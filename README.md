# 🌴 Тики-Пати

Браузерная настольная вечеринка в духе party-игр: от 2 до 6 игроков онлайн, боты, одна карта («Остров Тики») и 10 мини-игр, которым не важны пинг и скорость реакции.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run sim 10     # прогон 10 партий ботами без графики (проверка логики)
```

## Как играть онлайн

1. Хост нажимает «Создать онлайн-комнату» и отправляет друзьям код или ссылку-приглашение.
2. Друзья открывают ссылку (или вводят код) и выбирают персонажа.
3. Хост при желании добавляет ботов и нажимает «Начать игру».

Свой сервер не нужен. Браузеры соединяются напрямую по WebRTC (PeerJS), публичный сервер PeerJS нужен только для «знакомства». Вся логика выполняется в браузере хоста, остальные получают события и отвечают на вопросы.

- **Обрыв связи у игрока.** За него сразу начинает ходить бот. Чтобы вернуться в ту же партию, достаточно снова зайти по коду.
- **Хост закрыл вкладку.** Партия сохраняется в начале каждого хода. В меню хоста появится «Продолжить сохранённую игру»: комната откроется с тем же кодом, и игроки перезаходят.
- **Таймер.** На ход даётся 60 секунд, на остальные решения 30 секунд, потом решает бот.
- **Строгий NAT.** Без TURN-сервера прямое соединение иногда не устанавливается (корпоративные сети, некоторые мобильные операторы). Если не подключается, попробуйте другую сеть.

## Правила

- Старт: 10 монет. Звезда стоит 20 монет; купить её можно, проходя мимо или вставая на её клетку. После покупки звезда перелетает в другое место.
- Побеждает тот, у кого больше всех звёзд, при равенстве — больше монет.
- Ход: обычный кубик 1–10, **кубик персонажа** (у каждого свой набор граней) или предмет.

| Клетка | Эффект |
|---|---|
| 🔵 Синяя | +3 монеты (+6 в последние 5 ходов) |
| 🔴 Красная | −3 монеты (−6 в последние 5 ходов) |
| ❓ Событие | Кокосовый дождь, течение, попугай-шутник, вулкан, дельфин, шторм, прилив |
| 🍀 Клевер | Предмет или монеты |
| ☠ Барракуда | Пиратские пакости: налог, революция, наценка на звезду, обмен кошельками… |
| ⚔ Дуэль | Вызываешь соперника на мини-игру со ставкой |
| 🐢 Банк | Проходя мимо, кладёшь 5 монет; встав на клетку, забираешь всё |
| 🛒 Лавка | Проходная: покупка предметов |
| 🐒 Воришка | Проходная: украсть монеты (5) или звезду (40) |

Предметы (до 3 в рюкзаке, один за ход): двойной кубик, тройной кубик, кубик-выбор, волшебная ракушка (телепорт к звезде), свиток обмена местами, лапа воришки, капкан.

Последние 5 ходов: синие и красные клетки удваиваются, а игрок на последнем месте получает 10 монет. В конце раздаются 3 случайные бонусные звезды из 6 (мини-игры, богач, приключения, невезение, транжира, путешественник).

### Мини-игры

Формат определяется цветом клетки, на которой каждый закончил ход: «каждый сам за себя», «1 против всех», «команда на команду». Дуэли идут отдельно.

**Стратегия и удача.** Все выбирают одновременно, хост открывает результат:
- Сундуки пирата: совпавшие делят добычу.
- Аукцион попугая: тайные ставки.
- Сокровища вулкана: рискнуть или уйти.
- Ракушки на песке: очки приносит только уникальное число.
- Прятки в джунглях: 1 против всех.

**Навык.** Каждый играет у себя с одинаковым seed, хосту уходит только счёт:
- Фруктопад
- Меткий кокос
- Парные ракушки
- Перепись крабов
- Барабаны тики

## Архитектура

```
src/core/      логика без DOM: хост, боты, карта, мини-игры (работает и в node)
src/net/       PeerJS-транспорт
src/client/    интерфейс: меню/лобби (DOM), доска (Phaser 3), мини-игры, звук (Web Audio)
tools/         симуляция партий
```

Тестовый сервер сигналинга: `npx peerjs --port 9000 --host 127.0.0.1`, затем открыть `?peer=127.0.0.1:9000`.
Если в одном браузере нужно несколько игроков, добавьте `&tab=2` к адресу: так у вкладки будет свой ID игрока.
